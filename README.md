# DL Customer Churn Project

This repository contains the data, notebooks, and presentation files for the **Customer Churn** deep‑learning analysis.

## Contents

- `Vandana_Customer_Churn_DL.ipynb` – Jupyter notebook with data preprocessing, model building, and evaluation.
- `Vandana_Customer_Churn_DL.pptx` – Presentation summarizing the approach and results.
- `cleaned_customerchurn_dataset.csv` – Cleaned dataset used for training and testing.

## How to use

1. Install the required Python packages (e.g., `pandas`, `numpy`, `scikit-learn`, `tensorflow`).
2. Open the notebook and run the cells sequentially.
3. Explore the results and adapt the model as needed.
